# HIMURA SWITCH PS4 — R13 01.13 / HIMU00011: PS4 Vulkan safe-path experiment
27 November 2026

## Scope and confirmed baseline
The owner has identified the R13 source-based branch as the desired restoration target: `HIMU00011`, version `01.13`. The previous R13 passed CI but actual PS4 Pro tests found Silksong entering its introduction and then hanging/crashing around gameplay transition, Mario Kart 8 Deluxe stuck at title, and another game loading without reaching gameplay (see `docs/R13_TESTES_REAIS_2026-11-26.md` on the parent branch).

**Do not confuse these sources:** R13 is based on `xatyy/Eden4` commit `fab246cbac93c7995aaf451dca83ae93ba0bd234`. The working New Eden 04.89 is a distinct, precompiled PS4 binary; its exact corresponding source is not identified. It is therefore *not established* that any patch here was taken from New Eden 04.89. The public **Orbis-EDEN** source commit `f004df1c7a812cc65703d8f937d0bd12a6d06a58` is the reference for this experiment.

## One isolated PS4 GPU change in this branch
- Port only the behavior described in Orbis-EDEN `patches/eden/0009-PS4-avoid-RADV-GFX7-GPU-hangs-from-indirect-count-dr.patch`, translated to the `__OPENORBIS__` macro used by the pinned Eden4 source.
- In `src/video_core/macro.cpp`, for PS4 only, route HLE multi-draw-indirect-count to the existing `Fallback` individual draw path. Preserve normal behavior outside PS4.
- In `src/video_core/vulkan_common/vulkan_device.cpp`, for PS4 only, disable conditional rendering and indirect-count extensions before creating the logical Vulkan device.
- The patch script checks both exact anchors before writing either file and refuses changed/unexpected source. Tests check insertion and refusal on double application.
- CI preflight downloads the two actual files from the pinned source, applies all R13 patches and validates these additions; the CircleCI experimental branch is isolated from the working R13.
- No changes to JIT, emulator CPU accuracy, saves, game keys, firmware, source directory persistence, metadata or installed PKG identity. Approved samurai icon/menu and existing game-carrousel workflow remain unaffected by this first GPU experiment.

## Acceptance test before calling any change a fix
1. CI preflight: patch applies exactly and regression tests pass, no unexpected source mutations.
2. Experimental PKG: ELF and PKG generated by the R13 toolchain. Do **not** overwrite the known working New Eden 04.89 backup.
3. Real PS4: app installs and reaches interactive R13 menu; samurai icon and backdrop remain correct.
4. Silksong: time launch -> menu -> intro -> **playable gameplay**, and test audio, Vulkan stability, memory and return to library for 10+ minutes.
5. Mario Kart 8 Deluxe and second game: determine precise transition and collect logs; no estimated FPS or success claims.
6. Compare A/B against the original R13 using identical game/update/firmware/keys, recording `HIMURA_R13_GAME_STATUS.txt`, `eden.log`, `crash.log`, `boot-trace.log` (never record keys).
7. If the change does not work, revert to unmodified R13 and investigate memory/JIT separately.
